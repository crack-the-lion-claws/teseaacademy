# TESEA Academy

TESEA Academy is an educational platform designed for secondary school students following the NECTA and Cambridge curricula, featuring interactive courses, quizzes, practice modes, AI study assistance (Rafiki AI), and progress tracking.

## Features
- Comprehensive course catalog (Form 1 - Form 4 NECTA & Cambridge)
- Interactive Quiz Studio and Brain Puzzles
- Mock Exams with instant feedback
- Student Progress & Analytics Dashboard
- Teacher Management Portal
- Secure Authentication & Subscription Management

# Tutor Class Management QA

- Classes page routes to dedicated Create Class studio.
- Create Class persists a new class in localStorage and routes to the new class workspace.
- Class cards open the selected class management workspace.
- Class Management links to roster/evidence, Assignment Centre, Live Lesson Studio and Community Center.
- Quick Assignment / Topic Test / Exam actions route to the dedicated assessment builders.
- Quick Live Lesson routes to the focused Live Lesson Studio.
- API contracts include class CRUD, roster import, assessment assignment, live-session assignment and evidence aggregation endpoints.
- Existing Content Studio, Assessment Studio, Live Lessons, Community Center and Question Bank routes remain preserved.
